Duck Game Friends

For 2–4 people on Apple Silicon Macs running macOS 15 or later.

First launch

This custom app is Developer ID signed but not Apple-notarized. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway after attempting to launch it. Only do this for the copy you received from your host. Do not disable Gatekeeper globally.

Set up once

  1. Drag Duck Game Friends into Applications. Mono and the five custom maps are included.
  2. Open Install Tailscale.pkg from this disk image, or download Tailscale for Mac. Approve its network extension and VPN configuration, then sign in with your own account.
  3. The host creates a personal Tailscale network and invites the other three players. Each friend accepts and connects their Mac to that same network. Do not share account passwords. Each friend keeps their own login.

Play together

  1. Everyone opens Duck Game Friends and clicks Refresh. It should say Connected to Tailscale.
  2. One person clicks Host four-player game. A room code is copied automatically. Send that code privately to your friends; it includes the room password.
  3. Friends paste the code and click Join game. Pick your ducks in the game lobby, then enter the ready area to start.
  4. Keep Tailscale connected and the host’s game open. A new hosting session gets a new room code.

Your five maps

In the lobby: Match Settings → Custom Levels → Divits Favorite Remixes. Enable the maps. Set Custom Levels to 100% to play only those selected maps.

If joining fails

Check that all four Macs are in the same Tailscale network, all players use this same Friends build, and the host is still in the lobby. Paste a fresh room code. If macOS asks about incoming connections for the game, allow it for multiplayer. No router port forwarding is required. Quit the game before switching rooms.

Local verification covers four separate game processes. Real internet latency and a second physical Mac still need a first-session test. Mid-match joining is disabled for this LAN build; gather in the lobby before starting.

This package includes the upstream DuckGameRebuilt game content and local networking fixes. It is not an official Duck Game release. Keep your own legitimate game copies. Logs: ~/Library/Logs/DuckGameFriends/game.log.

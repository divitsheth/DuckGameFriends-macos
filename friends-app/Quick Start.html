Duck Game Friends

For 2–8 people, each on their own computer: a Mac (Apple Silicon with macOS 15 or later, or Intel with macOS 11 or later) or a Windows 10 or 11 PC. Macs and PCs can play together. Nothing else to install, no accounts, and no router setup.

First launch

Mac: drag Duck Game Friends into Applications and open it. This custom app is Developer ID signed but not Apple-notarized. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway after attempting to launch it. Only do this for the copy you received from your friend. Do not disable Gatekeeper globally.

Windows: right-click the downloaded zip and choose Extract All, then open the Duck Game Friends folder and double-click Duck Game Friends.exe. The app is not signed for Windows, so Windows may say “Windows protected your PC”: click More info → Run anyway. If Windows Firewall asks, allow access.

Play together

The game opens on the Duck Game Friends menu. Use the arrow keys and Space or Enter, or a controller (A to select, B to go back).

  1. One person picks HOST A ROOM. The lobby opens with the room code, such as K7QD-2MXH, pinned at the top. It is also copied, so paste it to your friends.
  2. Friends pick JOIN A ROOM. A code you copied is filled in for you; otherwise type it or press ⌘V (Ctrl+V on Windows). Press Enter to join.
  3. Pick your ducks in the lobby, then enter the ready area to start. Everyone must join before the match starts.
  4. The host keeps their game open while you play. Leaving the lobby returns to the menu; each new room gets a new code.

Your five maps

In the lobby: Match Settings → Custom Levels → Divits Favorite Remixes. Enable the maps. Set Custom Levels to 100% to play only those selected maps.

If joining fails

No room with that code: check the code with the host and make sure their game is still running. Can’t reach the server: check your internet connection. Everyone should use Duck Game Friends 1.1 or newer; for more than four players, everyone needs 1.3 or newer. Windows players need 1.5 or newer.

Games connect through a small Duck Game Friends relay server, so they work across different homes and networks. Keep room codes private: anyone with the code can join while there is a free slot.

This package includes the upstream DuckGameRebuilt game content and local networking changes. It is not an official Duck Game release. Keep your own legitimate game copies. Logs: ~/Library/Logs/DuckGameFriends/game.log on a Mac, %APPDATA%\DuckGame\ducklog.txt on Windows.
